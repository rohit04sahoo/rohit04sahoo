### 📖 Introduction

I'm a passionate Software Developer with hands-on experience building scalable cross-platform mobile applications using **Flutter** and developing robust backend APIs with **Django REST Framework**. I enjoy transforming complex business requirements into clean, user-friendly, and high-performance applications.

My experience includes developing real-world applications in fleet management, logistics, vehicle booking, and service management systems, where I've worked across the complete development lifecycle — from UI/UX implementation to backend integration and deployment.

- 🎨 **UI/UX Design:** Design modern, responsive, and premium user interfaces
- 🔗 **API Integration:** Integrate REST APIs and manage backend communication
- ⚙️ **Backend Engineering:** Build backend services using Django REST Framework
- 🗄️ **Database Management:** Design and integrate MySQL / SQLite databases
- 🔐 **Security:** Implement authentication, authorization, and secure APIs

- 🚀 **Optimization:** Optimize application performance and user experience
